# Audit Log: 2026-06-09

Foundational audit pass against The Pragmatic Programmer principles
plus React Native a11y and dep vuln scan. PR: `audit/2026-06-09` →
main.

## Shipped in this PR

**Dependency vulnerabilities (`/vuln`):**
- `npm audit fix` resolved the **1 critical** (shell-quote CVSS 8.1)
  + **9 high** + 4 of the 17 moderate severities. Vuln count went
  from **28 → 14** (all remaining are moderate, all transitive via
  Expo SDK).
- The 14 remaining moderates are inside `expo/config-plugins` and
  related Expo SDK build-time tooling. Fixing them requires an Expo
  SDK version bump, which is a separate scoped decision (SDK
  upgrades come with compatibility work).

**Accessibility (`/a11y`) on the React Native UI:**
- Added `accessibilityRole="button"` + `accessibilityLabel` to the
  three primary interactive controls in `App.js`:
  - The primary timer button (Start / Pause / Resume — the label
    follows the current state).
  - The "Stop" button, which also now propagates
    `accessibilityState={{ disabled: !phaseEndAt }}` so the screen
    reader announces "dimmed" when the timer hasn't been started.
  - The "Support PomodoroFlow" tip-jar trigger button (iOS only).
- Screen reader users now hear "Start, button" instead of just
  "Start" — clearer role announcement.

**Orthogonality (`/coupling`):**
- The architecture is intentionally consolidated (per CLAUDE.md, "all
  timer logic lives in App.js"). The services layer
  (`AnalyticsService`, `ReviewPromptService`, `StreakService`,
  `TipJarService`) is leaf-pure — each service imports only from
  `config/monetization.ts` and `expo-*`, and is consumed by App.js.
  Clean fan-in. No cycles, no cross-service imports.

**DRY (`/drift`):**
- Storage keys + all numeric constants live in
  `config/monetization.ts`. App.js imports them. No drift.
- One small magic number trail flagged for future review: the
  `25 * 60` / `5 * 60` focus/break durations are inline in App.js
  rather than referenced from `monetization.ts`. Out of scope for
  this PR; the constants are unambiguous and named with comments.

**Broken windows (`/zombie`):**
- Zero commented-out code, zero TODOs/FIXMEs/HACKs, zero empty
  catches in App.js or services.

**Walkthrough (`/walkthrough`) of the state machine:**
- State machine is `phase × running × phaseEndAt`:
  - IDLE: `running=false, phaseEndAt=null`
  - RUNNING: `running=true, phaseEndAt=<future epoch>`
  - PAUSED: `running=false, phaseEndAt=null` (cleared on pause)
- Cold-start with `phaseEndAt` already in the past: the foreground
  `AppState` listener clamps `remaining` to 0, and the running
  interval triggers the focus↔break auto-transition. Verified by
  reading App.js:164-171 and the interval at lines 295-335.
- No render-state flash on launch — SplashScreen is the gate.

## Out of scope (declined / not in this PR)

## Onlooker takeaway

A tightly-scoped Expo app. Single-file timer logic is intentional
("Radical simplicity — 25/5 on loop"). The audit's most visible
change is making the primary timer controls announce themselves
correctly to screen readers, plus closing the 1-critical + 9-high
dep-vuln cluster.
