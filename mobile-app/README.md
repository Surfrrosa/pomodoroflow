# PomodoroFlow Mobile App

Simple 25/5 Pomodoro timer. Free forever, tip jar only, no accounts.

## Quick start

```bash
npm install
npm start          # Expo dev server
npm run ios        # iOS simulator
npm run android    # Android emulator
npm test           # Jest
npm run typecheck  # TypeScript
npm run lint       # ESLint
```
